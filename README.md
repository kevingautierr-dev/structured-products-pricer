# newsmacro

Branche séparée du dépôt, sans lien avec le code du pricer (`main`).

Elle sert à la publication quotidienne du carrousel Instagram **@newsmacro115** :

- `kit/` : génération du carnet « Briefing et pitch » (.docx), des slides (1080 × 1350) et de la légende.
- `posts/AAAA-MM-JJ/` : les images publiées chaque matin (liens publics lus par Metricool).
- `RUNBOOK.md` : la procédure suivie chaque matin de semaine à partir de 7 h 35.
- `examples/` : le contenu du 3 novembre 2026, référence du format validé.

Polices : Archivo et IBM Plex Mono, licence SIL Open Font License (fichiers OFL dans `kit/fonts`).
